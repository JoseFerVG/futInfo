Conexión a Base de Datos Firebase (Gratis)

Usa el plan gratuito Spark de Google Firebase para tener base de datos en tiempo real y login para todo tu equipo.

¿Cómo activar Firebase en 3 minutos?

  1. Entra en la consola gratuita de Firebase Console con tu cuenta de Google.
  2. Crea un proyecto (ejemplo: torneo-rector-fc). El plan gratuito incluye 1 GB de Firestore y 50k usuarios de Auth.
  3. En la sección Compilación: activa Authentication (proveedor Correo electrónico/contraseña) y crea una base de datos Firestore Database.
  4. En la rueda de engranaje (Configuración del proyecto), añade una app Web </> y copia tu firebaseConfig.
  5. Pega abajo tus credenciales y pulsa Guardar y Conectar.
